# DriftSense-FM

**Physics-guided, periodicity-aware localization for the fixed 10× reference-to-search scale mismatch in semiconductor navigation-error recovery.**

## Status

This repository is an offline, CPU-only, deterministic baseline suitable for hackathon submission packaging. The GitHub repository supplied for this task was empty, so the implementation is built from the accompanying solution proposal and build specification. Local numbers are generated by the included harness and must not be presented as official hidden-challenge results.

The submission package includes an MIT license, a pinned Python 3.11 runtime, GitHub Actions CI, strict input validation, reproducible synthetic-data metadata, measured benchmark and ablation artifacts, and a 13-test regression suite.

## Quickstart

```bash
python3 -m pip install -r requirements.txt
# Fast compact fixtures for routine tests and benchmark reports.
python -m generator.make_dataset --fast
# Optional: true 10000x10000 continuous latent scenes; CPU/memory intensive.
# python -m generator.make_dataset --full
python benchmark/run_benchmark.py
python benchmark/ablation.py
python run.py <input-dir> <output-dir>
```

The runtime path needs only NumPy and OpenCV. It makes no network requests, downloads no model, needs no API key, and does not require a GPU. The optional reranker is not part of the baseline and is not imported unless separately enabled by a future extension.

## Input and output contract

The CLI accepts a directory containing `pairs.csv` with columns `id,reference,search`, a single `reference.npy` and `search.npy`, or multiple `<id>_reference.npy` and `<id>_search.npy` pairs. Official mode validates finite numeric grayscale arrays of shape `1000×1000`; use `--dev` only for small local unit fixtures.

The output directory contains `predictions.csv` with `id,x,y,confidence` and one JSON diagnostics file per input pair. Coordinates are target-center coordinates in search-image pixels. Diagnostics include the score margin, top candidates, dominant pitch, all component scores, confidence, and the `high_confidence` or `periodic_ambiguity` label. Malformed CSV rows, duplicate IDs, missing files, invalid parameters, non-finite arrays, and shape violations fail with explicit errors.

## Architecture

| Module | Responsibility |
|---|---|
| `driftsense/io_utils.py` | Array validation, pair discovery, CSV and JSON output. |
| `driftsense/calibration.py` | Fixed known-scale 1000×1000 to 100×100 area downsampling. |
| `driftsense/candidates.py` | Intensity, squared-error, gradient, and high-pass response maps with coordinate NMS. |
| `driftsense/scoring.py` | Fourier magnitude, lattice pitch, gradient phase, boundary, and deterministic final score. |
| `driftsense/subpixel.py` | Independent quadratic refinement around response peaks. |
| `driftsense/tiebreak.py` | Declared score-margin and image-center ambiguity rule. |
| `driftsense/diagnostics.py` | Auditable confidence and candidate diagnostics. |
| `generator/` | Seeded procedural DRAM-like fixtures and per-case JSON configuration. |
| `benchmark/` | Measured benchmark and profile-specific ablation harnesses, with Markdown and JSON reports. |

The deterministic score is `0.30 intensity + 0.15 squared-error + 0.18 gradient + 0.12 high-pass + 0.10 Fourier + 0.10 lattice consistency + 0.05 boundary`. Candidate generation is intentionally diverse because repeated semiconductor structure can produce several visually similar local maxima.

## Local diagnostic benchmark

Run `python benchmark/run_benchmark.py` after generating the diagnostic data. The generated report is written to `benchmark/reports/benchmark_results.md` and JSON. The included compact fixture generator creates 20 ID visible-anchor cases, 10 OOD visible-anchor cases, and 5 hard ambiguous periodic cases with recorded seeds and ground truth.

The currently measured local results are:

| Split | Cases | Strict ±0.5px | Relaxed ≤1px | Mean Euclidean error | Mean runtime/pair |
|---|---:|---:|---:|---:|---:|
| ID visible-anchor | 20 | 18/20 | 20/20 | 0.169 px | 0.240 s |
| OOD visible-anchor | 10 | 8/10 | 9/10 | 0.234 px | 0.258 s |
| Hard ambiguous periodic | 5 | 1/5 | 1/5 | 193.091 px | 0.294 s |

These are measured on the included compact synthetic fixtures, not official challenge data. The visible-anchor splits contain a discriminative asymmetric feature by design. The hard split removes that information and is an honesty artifact: a periodic scene without a distinguishing cue is expected to remain ambiguous. Therefore, local visible-anchor success must not be overclaimed as proof of periodicity-aware superiority or official challenge performance.

## Ablation

`python benchmark/ablation.py` evaluates `intensity_only`, `+gradient`, `+high_pass`, `+squared_error_agreement`, `+fourier_agreement`, and `driftsense_fm_full`. Each profile recomputes its own candidate set and final score. The measured local ablation is:

| Profile | ID strict | OOD strict | Hard periodic strict | ID mean error | OOD mean error |
|---|---:|---:|---:|---:|---:|
| intensity_only | 18/20 | 8/10 | 2/5 | 0.192 px | 0.252 px |
| +gradient | 19/20 | 8/10 | 2/5 | 0.188 px | 0.249 px |
| +high_pass | 18/20 | 8/10 | 2/5 | 0.166 px | 0.232 px |
| +squared_error_agreement | 18/20 | 8/10 | 1/5 | 0.170 px | 0.235 px |
| +fourier_agreement | 18/20 | 8/10 | 1/5 | 0.169 px | 0.234 px |
| driftsense_fm_full | 18/20 | 8/10 | 1/5 | 0.169 px | 0.234 px |

The meaningful future experiment is an adversarial near-decoy matrix containing identical repeated tiles, near-identical neighbors, missing/noisy contacts, pitch variation, brightness shifts, blur, partial defects, boundary truncation, global drift, local row distortion, and altered neighboring lattice phase. The engineering targets of at least 80% ID strict and 60% OOD strict on that future held-out matrix are targets, not current claims.

## Known scope and limitations

The baseline is grayscale and DRAM-family oriented. FinFET rendering, RGB support, and a learned reranker remain extension tracks. The compact local fixtures are designed for fast reproducibility and contract testing; they are not proprietary process data and are not a substitute for the official challenge set.

## Reproducibility

All diagnostic cases store seed, pitch, mode, anchor status, and ground-truth metadata in per-case JSON files. The data arrays are generated locally and ignored by Git to keep the repository lightweight. Run `python -m unittest discover -s tests -v` for the deterministic test suite. GitHub Actions runs the same suite on every push and pull request. The pinned runtime is Python 3.11 (`runtime.txt`, `pyproject.toml`).
